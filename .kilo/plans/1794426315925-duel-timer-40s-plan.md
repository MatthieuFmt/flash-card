# Plan — Chrono 40 s + « Je ne sais pas » en mode Duel (quizz)

## Objectif

Dans le mode Duel 2 joueurs (`js/ui/duel.js`), le joueur qui buzze a actuellement un temps illimité pour taper le nom du pays. Ajouter :

1. **Chrono de 40 s** qui démarre au moment du buzz (phase de saisie uniquement, validé avec l'utilisateur).
2. **Bouton « Je ne sais pas »** dans la zone de saisie qui permet de passer directement à l'autre joueur, ou de terminer la manche si l'autre joueur a déjà tenté sa chance.

## Décisions validées

- Le chrono **démarre au buzz**, pas dès l'affichage du drapeau. Phase buzz inchangée (sans limite).
- Expiration du chrono = même traitement qu'une mauvaise réponse :
  - 1er joueur (celui qui a buzzé) → passe à l'autre joueur avec un nouveau chrono de 40 s.
  - 2e joueur → fin de manche, réponse révélée, personne ne marque.
- « Je ne sais pas » = même logique que l'expiration (passer ou terminer la manche), avec un message adapté.
- Durée fixe `40` via une constante `ANSWER_TIME_S` dans `duel.js`.
- Bonne réponse / fin de manche / manche suivante / quitter / revanche → le chrono est arrêté et réinitialisé.

### 3. `js/ui/duel.js` — logique du chrono et du « Je ne sais pas »

**État (en haut du module, avec les autres `let`)** :
```js
const ANSWER_TIME_S = 40;
let timerId = null;
let timeLeft = 0;
```

**Nouvelles fonctions** :

- `startTimer()` : `clearTimer()` d'abord ; `timeLeft = ANSWER_TIME_S` ; retirer la classe `warning` ; `timerId = setInterval(tick, 100)` ; `renderTimer()`.
- `renderTimer()` : met à jour `#duel-timer-text` (`Math.ceil(timeLeft) + "s"`) et la largeur de `#duel-timer-fill` (`(timeLeft / ANSWER_TIME_S) * 100 %`) ; ajoute la classe `warning` si `timeLeft <= 10`.
- `tick()` : `timeLeft -= 0.1` ; si `timeLeft <= 0` → `clearTimer()` puis `giveUp(null)` (timeout) ; sinon `renderTimer()`.
- `clearTimer()` : `clearInterval(timerId)`, `timerId = null`.
- `giveUp(reason)` : extrait la logique « passer ou terminer » existante de `submitAnswer` (lignes 153-167) :
  - si `buzzed === roundBuzzer` (1er joueur) : bascule sur l'autre joueur (classes buzzer, label « … à toi de trouver le pays : », input vidé, focus), message de feedback adapté (« `name` ne sait pas ! `other` peut tenter sa chance ! » ou « ⏳ Temps écoulé ! `other` peut tenter sa chance ! »), puis `startTimer()`.
  - sinon (2e joueur) : `endRound()` + `showFeedback(reason === "idk" ? "Personne ne marque !" : "Temps écoulé, personne ne marque !", false, currentCountry.name)`.

**Modifications des fonctions existantes** :

- `buzz(player)` : appeler `startTimer()` après avoir affiché `#duel-answer-area` et donné le focus.
- `submitAnswer(value)` : en cas de bonne réponse → `clearTimer()` avant `endRound()`. Remplacer le bloc « mauvaise réponse » (lignes 153-167) par un appel `giveUp("wrong")` (message actuel conservé).
- `endRound()` : `clearTimer()`.
- `renderRound()` : `clearTimer()` + masquer/réinitialiser le chrono.
- `quit()` : `clearTimer()`.
- `init()` : listener sur `#duel-idk-btn` → si `answerLocked || !buzzed` return, sinon `giveUp("idk")`.

**Points d'attention** :

- `answerLocked` est mis à `true` par `endRound()` → bloque le « Je ne sais pas » et les soumissions pendant le feedback/la manche suivante, comme aujourd'hui.
- Le 2e joueur reçoit bien un chrono de 40 s complet (via `startTimer()` dans `giveUp`).
- Le chrono est purement visuel/JS, aucun impact sur le score ni sur les statistiques (rien à changer dans `storage.js`/`srs.js`).

## Validation (manuelle, pas de suite de tests dans ce projet)

Ouvrir `index.html` dans un navigateur, lancer un Duel :

1. Buzz J1 → le chrono apparaît à 40 s et décompte ; sous 10 s il passe en rouge.
2. J1 ne répond pas → à 0 s : message « Temps écoulé », J2 obtient la main + nouveau chrono 40 s.
3. J2 clique « Je ne sais pas » → fin de manche, réponse révélée, personne ne marque, bouton « Manche suivante ».
4. J1 clique « Je ne sais pas » → J2 prend la main (chrono relancé) ; J2 répond correctement → +1 J2, chrono arrêté, pas de fuite de timer.
5. J1 répond correctement → chrono arrêté, confettis, aucune exécution tardive du tick.
6. Quitter / Revanche en cours de chrono → aucun timer résiduel (la manche suivante démarre proprement à 40 s).
7. Vérifier l'absence d'erreurs dans la console navigateur.
